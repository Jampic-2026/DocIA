Los valores de ejemplo sirven para documentación y desarrollo; no sustituyen las credenciales actuales. `api.env` y `migrations.env` se copian por separado desde el despliegue anterior. La preparación comprueba cada valor no gestionado después de retirar las URL centrales, incluidas claves desconocidas, contraseñas con # y valores multilínea.

`PUBLIC_LANDING_URL` pertenece al archivo público central y no es una variable que la API original necesitara. `DOCIA_SITES_FILE` y `DOCIA_RELEASE` los fija PM2 por release; `DOTENV_CONFIG_PATH` lo fija el comando de migraciones.

Para regenerar: `npm run audit:api-env`. Para probar la conservación de valores: `npm run test:api-env`, después de instalar las dependencias de API.
